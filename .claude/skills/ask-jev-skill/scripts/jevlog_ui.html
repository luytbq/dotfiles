DDL (view search_v, bảng calls, questions)

Nội dung ô WHERE được chèn vào câu lệnh dưới đây. Có thể dùng subquery tới bảng calls và questions, ví dụ id IN (SELECT call_id FROM questions WHERE type = 'score' AND confidence < 0.5).
